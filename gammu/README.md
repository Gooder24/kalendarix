# Kalendarix → telefón cez Gammu

Tieto skripty nahrajú kalendár vyexportovaný z Kalendarixu (súbor `.vcs`)
priamo do starého telefónu pomocou nástroja **Gammu**.

Každý skript existuje v dvoch verziách: `*.bat` pre **Windows** a `*.sh`
pre **macOS / Linux** (rovnaké správanie).

| Skript (Windows / macOS·Linux) | Telefóny | Formát |
|--------|----------|--------|
| `nokia-s40.bat` / `nokia-s40.sh` | Nokia Series 40 (3310, 6300, C2-01, 6700, Asha) | vCalendar 1.0 |
| `nokia-s60.bat` / `nokia-s60.sh` | Nokia S60 / Symbian (N95, E71, 6600, N70) | iCalendar 2.0 |
| `sonyericsson.bat` / `sonyericsson.sh` | Sony Ericsson (W800, K750, W810, K800) | vCalendar 1.0 |
| `generic.bat` / `generic.sh` | Motorola, Samsung, Siemens/BenQ a ostatné | vCalendar 1.0 |

---

## 1. Inštalácia Gammu (jednorazovo)

### Windows

1. Stiahni Gammu pre Windows: <https://wammu.eu/gammu/> (sekcia *Download*).
2. Nainštaluj do `C:\Program Files\Gammu` (skripty očakávajú
   `C:\Program Files\Gammu\bin\gammu.exe`). Ak je inde, uprav riadok
   `set GAMMU=...` v príslušnom `.bat`.
3. Over inštaláciu:
   ```
   "C:\Program Files\Gammu\bin\gammu.exe" --version
   ```

### macOS

```
brew install gammu
gammu --version
```

### Linux

```
sudo apt install gammu       # Debian / Ubuntu / Mint
sudo dnf install gammu       # Fedora / RHEL
sudo pacman -S gammu         # Arch / Manjaro
sudo zypper install gammu    # openSUSE
gammu --version
```

`.sh` skripty hľadajú `gammu` v `PATH`. Ak ho máš inde, spusti skript s
premennou: `GAMMU=/cesta/ku/gammu ./nokia-s40.sh`.

> **Linux — prístup k USB portu.** Aby Gammu videl telefón bez `sudo`, pridaj
> sa do skupiny `dialout` (Debian/Ubuntu/Arch) alebo `uucp` (Fedora):
> `sudo usermod -aG dialout $USER`, potom sa odhlás a prihlás.

## 2. Pripojenie telefónu (USB režim)

Najčastejšia príčina „telefón nenájdený“ je nesprávny USB režim. Po pripojení
kábla telefón obvykle ponúkne menu — vyber **dátový / telefónny režim**, NIE
„veľkokapacitné úložisko / File transfer / MSC“.

| Značka | Správny USB režim |
|--------|-------------------|
| Nokia S40/S60 | **PC Suite** (nie „Mass storage“ / „Media transfer“) |
| Sony Ericsson | **Phone mode** (nie „File transfer“) |
| Motorola | **Motorola Phone Tools / Modem** (nie „USB Mass Storage“) |
| Samsung | **Samsung PC Studio / Modem** |
| Siemens / BenQ | dátový kábel + **Modem** profil |

> Tip: ak telefón nemá USB, ale má Bluetooth, Gammu vie použiť aj BT — pozri
> sekciu *gammurc* nižšie.

## 3. Nastavenie Gammu (gammurc)

Gammu potrebuje vedieť, na ktorom porte telefón počúva. Najjednoduchšie:

```
gammu-detect
```

Výstup (príklad):

```
; Configuration file generated by gammu-detect.
[gammu]
device = com7:
name = Phone on COM port 7
connection = at
```

Skopíruj blok `[gammu]` do súboru `gammurc`:

- ulož ho buď do `%USERPROFILE%\gammurc`, alebo vedľa `gammu.exe`,
- bežné hodnoty `connection`:
  - `at` — väčšina Nokií S40, Sony Ericsson, Samsung, Siemens (AT cez modem),
  - `at115200` — ak `at` je pomalé/nestabilné,
  - `symbian` alebo `blueobex`/`irdaobex` — niektoré S60 cez OBEX.

Over spojenie:

```
"C:\Program Files\Gammu\bin\gammu.exe" identify
```

Príklad úspešného výstupu:

```
Device               : com7:
Manufacturer         : Nokia
Model                : 6300 (RM-217)
Firmware             : 07.20
IMEI                 : 35XXXXXXXXXXXXX
```

Ak vidíš `Manufacturer`/`Model`, spojenie funguje a môžeš spustiť `.bat`.

## 4. Export a spustenie

1. V Kalendarixe otvor **Nastavenia → Export do telefónu**, vyber model, exportuj.
   Súbor ulož na **Plochu** ako `kalendarix-export.vcs`
   (skripty hľadajú práve `%USERPROFILE%\Desktop\kalendarix-export.vcs`).
2. Spusti skript pre svoju značku:
   - **Windows:** dvojklikom na `.bat`.
   - **macOS / Linux:** v termináli v tomto priečinku:
     ```
     chmod +x nokia-s40.sh   # raz, nastaví spustiteľnosť
     ./nokia-s40.sh
     ```
3. Skript spraví `gammu identify` (kontrola spojenia) a potom
   `gammu restore "<.vcs>"`, čím nahrá udalosti do kalendára telefónu.

> Iný názov/umiestnenie súboru? Uprav `set VCS=...` v `.bat`, alebo spusti
> `.sh` s premennou: `VCS=/cesta/k/export.vcs ./nokia-s40.sh`.

## 5. Známe zvláštnosti podľa značky

**Nokia Series 40**
- Maximálna dĺžka názvu udalosti ~40 znakov (Kalendarix oreže automaticky).
- Diakritika ide cez QUOTED-PRINTABLE/UTF-8 — funguje na väčšine modelov.
- Alarm = `AALARM` (absolútny čas), opakovania len jednoduché (D/W/MD/YM).

**Nokia S60 (Symbian)**
- Plný iCalendar 2.0: `VEVENT` + `VALARM` + `VTIMEZONE` + `UID`, kategórie.
- Časy sú viazané na zónu `Europe/Bratislava` (CET/CEST).
- Ak `restore` hlási chybu formátu, skús `gammu addnew "<.vcs>"`.

**Sony Ericsson**
- USB musí byť v „Phone mode“. V „File transfer“ Gammu telefón nevidí.
- Názov udalosti max ~35 znakov.
- Niektoré modely potrebujú `connection = at19200` v `gammurc`.

**Motorola RAZR / ROKR** (`generic.bat`)
- Len **ISO-8859-1** (Latin-1) — slovenská diakritika ako č/š/ž sa
  transliteruje na c/s/z. To je úmyselné, telefón ich nevie zobraziť.
- Bez poľa miesto (LOCATION), názov max ~32 znakov.
- USB režim „Modem“, nie „Mass Storage“.

**Samsung (feature)** (`generic.bat`)
- vCalendar 1.0, UTF-8. USB cez „PC Studio / Modem“.

**Siemens / BenQ-Siemens** (`generic.bat`)
- Najprísnejší: **bez opakovaní**, bez miesta, názov max ~30 znakov, Latin-1.

## 6. Riešenie problémov

| Príznak | Riešenie |
|---------|----------|
| `Telefon nenajdeny` | Skontroluj USB režim (kap. 2), spusti `gammu-detect`, over `gammurc`. |
| `Error opening device` / port obsadený | Zatvor PC Suite/PC Studio/Wammu — port drží iný program. |
| `No response in specified timeout` | Skús inú `connection` (`at`, `at115200`, `at19200`) alebo iný USB port/kábel. |
| Diakritika je „rozsypaná“ | Pre Motorolu/Siemens je to očakávané (Latin-1). Pre ostatné over, že export bežal cez správny profil. |
| `restore` zlyhá na S60 | Skús `gammu addnew "<.vcs>"` (pridá udalosti namiesto prepisu). |
| Udalosti sa nahrali, ale zlý čas | Skontroluj čas/zónu v telefóne; S60 používa `Europe/Bratislava`. |

Manuálne (bez skriptu):

```
# Windows
"C:\Program Files\Gammu\bin\gammu.exe" identify
"C:\Program Files\Gammu\bin\gammu.exe" restore "%USERPROFILE%\Desktop\kalendarix-export.vcs"

# macOS / Linux
gammu identify
gammu restore "$HOME/Desktop/kalendarix-export.vcs"
```

> Pozn.: `restore` môže prepísať existujúce položky kalendára. Ak chceš len
> pridávať, použi `addnew`.
